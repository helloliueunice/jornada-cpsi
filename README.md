# Jornada CPSI

Plataforma gratuita de apoio a compras públicas de inovação (Contrato Público para Solução Inovadora, LC 182/2021).

- Site: https://helloliueunice.github.io/jornada-cpsi/
- Radar com os dados do Observatório do CPSI (PGE-SP e Toolkit do Marco Legal de CT&I, 2ª edição, dados até 01/06/2026), diagnóstico do melhor caminho, processo guiado em 6 etapas, modelos em Word, conferência de minuta e agenda de prazos.
- Nesta versão pública, os dados de cada pessoa ficam salvos só no próprio navegador.

Ferramenta de apoio: não substitui o parecer jurídico nem a decisão da autoridade competente.
